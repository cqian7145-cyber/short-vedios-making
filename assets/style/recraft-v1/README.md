# recraft-v1 reference studies

This set contains five small, original, hand-authored SVG studies for the proposed
Tech Blue Editorial direction. They are not Recraft generations and do not establish
that a Recraft style ID is consistent. They cover a technical machine, branching
choice, abstract person, architectural/factory object, and isolated object. Convert
to a Recraft-supported raster format only when beginning the real custom-style
evaluation; preserve a clean silhouette and the same palette across all subjects.
