# Vibe Knowledge visual writing guide

The project aims for a cinematic, dark, academic, atmospheric, minimal, diagram-driven knowledge documentary. Use warm ivory copy, restrained semantic gold/cyan/red accents, generous empty space, connected diagrams, moving agents or particles, measured counts, and slow continuity. Keep visual copy short and scenes connected inside one world. Avoid PPT, dashboards, rounded UI cards, large blocks of text, cheap neon, narration assumptions, and frequent hard cuts.

See `docs/VISUAL_LANGUAGE.md`, `docs/EPISODE_FORMAT.md`, and `docs/SCENE_ENGINE.md`. JSON describes what happens; existing React/Remotion components control how it looks.
